# 文档 04：UI / UX 规范（UI & UX Specification）

> 适用读者：理解了系统架构（文档 03）的初学者。本文件是前端界面开发的"图纸"，把布局、控件、颜色、状态、占位文案全部写清楚。

**设计定位一句话：** 简洁、专业、科研仪表盘风格（像实验室监控台），**不是**医疗诊断系统的风格。视觉上传达"数据 + 科研 + 实时"。

---

## 2. 各区域功能说明

### ① 顶部导航栏（Header）
| 元素 | 说明 |
|---|---|
| 系统名 | 英文主标题 `EEG Emotion Recognition System`，中文副标题 `脑电情绪识别演示系统` |
| 后端连接状态 | 圆点 + 文字。已连接=绿色圆点 +「已连接」；未连接=红色圆点 +「未连接」。状态来自 `/api/health` 轮询，**不得本地伪造** |
| 当前模式标签 | `模拟数据模式`（第一版） / `真实数据模式（占位）`（未接入真实数据时显示为占位样式） |
| 帮助按钮 `[?]` | 打开 Ant Design `Drawer` 帮助抽屉，内置术语解释（可引用文档 01 术语表）、免责声明 |

### ② 左侧控制面板（ControlPanel）
五个卡片（`Card`）从上到下：**A 数据源 → B 信号与特征设置 → C 模型设置 → D 任务控制 → E 运行日志**。卡片之间用 `Divider` 或间距区分。

### ③ 主显示区（Main）
四个模块：A 实时波形图、B PSD 频谱图、C 情绪结果卡片、D 情绪历史记录。详见第 3 节控件清单。

### ④ 底部状态栏（Footer）
一条水平信息条，展示 6 项状态，全部来自后端接口 / WebSocket 推送。

## 3. 控件清单、默认值、交互反馈、禁用规则

### 3.1 A 数据源

| 控件 | 默认值 | 交互 / 反馈 | 禁用规则 |
|---|---|---|---|
| 数据源状态文本 | 「模拟数据」 | 显示当前数据源；未来加载真实数据后显示「已加载文件」 | 无 |
| 按钮 `加载 EEG 文件` | — | 点击 → `Upload` 弹窗选择文件 → **第一版上传后显示 `Alert`：`真实 SEED 数据解析功能待接入`**，不执行任何解析 | 无 |
| 文件格式提示 | `.mat（SEED 数据，后续支持）` | 静态文字 | — |

> 占位文案必须原样体现：`真实 SEED 数据解析功能待接入`。**绝对不要**假装已经能解析 `.mat` 并输出结果。

### 3.2 B 信号与特征设置

| 控件 | 选项 | 默认值 | 交互 / 反馈 | 禁用 / 占位 |
|---|---|---|---|---|
| 通道选择 `Select` | `代表通道（推荐）`、`全部 62 通道（性能模式，占位）` | `代表通道（推荐）` | 选择「全部 62 通道」→ 提示 `性能模式未实现，第一版仅显示 8 个代表通道` | 「全部 62 通道」标记为禁用或可选但给出提示 |
| 特征选择 `Select` | `原始波形（演示）`、`PSD 功率谱密度（演示/基础支持）`、`DE 微分熵（占位）` | `PSD 功率谱密度（演示/基础支持）` | 选择 DE → 提示 `DE 微分熵为占位选项，尚未实现` | DE 标记占位 |
| 频段说明 | δ 1–4 Hz / θ 4–8 Hz / α 8–13 Hz / β 13–30 Hz / γ 30–50 Hz | 全部展示 | 静态色块 + 文字，颜色与 PSD 图分区一致 | — |
| 说明文字 | — | — | 固定文案：`第一版特征选择主要用于演示与可视化；真实训练管线后续接入。` | — |

### 3.3 C 模型设置

| 控件 | 选项 | 默认值 | 交互 / 反馈 | 禁用 / 占位 |
|---|---|---|---|---|
| 模型 `Select` | `模拟分类器（默认，可运行）`、`SVM（预留模型接口）`、`CNN（占位）`、`CNN-LSTM（占位）` | `模拟分类器（默认，可运行）` | 切换模型 → 下方显示对应说明文案 | SVM/CNN/CNN-LSTM 均为占位，可选但必须伴随提示 |
| 模型说明区 | — | — | 根据选中项显示说明，例如：<br>`模拟分类器：当前可运行的演示分类器，输出为模拟结果。`<br>`SVM：模型接口已预留，真实推理待接入 SEED 特征后实现。`<br>`CNN / CNN-LSTM：占位选项，尚未实现。` | — |

> **红线**：不得让用户误以为占位模型具备真实推理能力。任何非「模拟分类器」的模型，若被选中仍触发识别，结果来源必须仍写 `模拟分类器` 并提示"所选模型尚未实现，当前仍使用模拟分类器"。

### 3.4 D 任务控制

| 按钮 | 初始状态 | 点击后行为 | 状态反馈 |
|---|---|---|---|
| `开始识别` | 可用（后端已连接时） | `POST /api/recognition/start` | loading；成功后变为「识别中」；日志追加 |
| `暂停波形` | 可用（识别中） | `POST /api/recognition/pause`（建议第一版并入 stop 语义或由后端 `state` 支持 paused） | 波形冻结，状态栏显示「已暂停」 |
| `继续波形` | 可用（暂停中） | `POST /api/recognition/resume` | 波形恢复滚动 |
| `停止识别` | 可用（识别中） | `POST /api/recognition/stop` | 成功后显示 `识别已停止`，结果卡片显示"当前无结果"或保留最近一次并标注已停止 |
| `重置演示` | 始终可用 | `POST /api/recognition/reset` | 清空结果与历史，回到初始状态 |

**禁用规则：**
- 后端未连接时，`开始识别` 置灰禁用；
- `暂停波形` 仅在识别中可用；`继续波形` 仅在暂停中可用；`停止识别` 仅在识别中可用；
- 所有按钮点击期间有 `loading` 反馈，防止重复点击；
- 后端返回错误时，`message.error` 提示并恢复按钮状态。

> 说明：第一版"暂停波形"可以是后端 `state["paused"]` 语义（暂停推送），也可以简单实现为前端停止刷新（但状态仍必须由后端确认）。**推荐实现后端 `paused` 字段**，保持单一事实来源。

### 3.5 E 运行日志

- 每条日志格式：`[HH:MM:SS] 消息内容`，例如：
  - `[15:20:01] 后端连接成功`
  - `[15:20:05] 已启动模拟 EEG 数据流`
  - `[15:20:10] 已完成一次情绪识别：平静，置信度 82%`
  - `[15:20:12] 真实 SEED 数据解析功能待接入`
- 新日志显示在最上方或最下方（二选一，推荐最上方 + 自动滚动到最新），最多保留 **50 条**，超出后丢弃最旧的；
- 日志类型可用不同颜色区分：info（默认）、success（绿）、warning（黄）、error（红）。

## 4. 颜色、字体、间距建议

### 4.1 整体配色（科研仪表盘风格）
| 用途 | 建议值（Ant Design 主题变量） | 说明 |
|---|---|---|
| 背景 | `#F0F2F5`（灰色背景）/ 卡片 `#FFFFFF` | 干净、专业 |
| 主色 | Ant Design 默认 `#1677FF` | 按钮、选中态 |
| 文字主色 | `#1F2329` / `#303133` | 标题与正文 |
| 次要文字 | `#86909C` | 状态栏、说明文字 |
| 边框 | `#E5E6EB` | 卡片描边 |

### 4.2 情绪视觉规范（全局统一）
| 情绪 | 内部标签 | 显示文字 | 主色 | 副色（进度条） | Emoji |
|---|---|---|---|---|---|
| 高兴 | `positive` | 高兴 | 绿色 `#52C41A` | `#73D13D` | 😊 |
| 平静 | `neutral` | 平静 | 蓝色 `#1677FF` | `#4096FF` | 😌 |
| 悲伤 | `negative` | 悲伤 | 红色 `#F5222D` | `#FF7875` | 😢 |

- 结果卡片的大字情绪文本 + `Tag` + 置信度进度条都使用对应情绪主色；
- 色弱用户考虑同时用 Emoji 与文字区分（已用 Emoji，故可接受）。

### 4.3 频段颜色（与 PSD 分区一致）
| 频段 | 范围 | 颜色 |
|---|---|---|
| δ | 1–4 Hz | `#FAAD14`（黄） |
| θ | 4–8 Hz | `#13C2C2`（青） |
| α | 8–13 Hz | `#52C41A`（绿） |
| β | 13–30 Hz | `#1677FF`（蓝） |
| γ | 30–50 Hz | `#722ED1`（紫） |

### 4.4 字体与间距
- 中文正文：系统默认（`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`）；英文标题可用稍大字号加粗；
- 波形图标题、卡片标题：14–16px、`font-weight: 600`；
- 情绪大字：28–36px 加粗；
- 卡片间距：12–16px；页面边距 16px；
- 图表中轴标签 11–12px，避免拥挤。

## 5. 空状态、加载状态、错误状态设计

| 场景 | 表现 |
|---|---|
| 空状态（初始加载） | 波形图显示"等待数据…"，结果卡片显示"暂无识别结果"，历史表格显示空占位 `暂无历史记录` |
| 加载状态 | 首次拉取 `/api/config` 时全局 `Spin`；按钮点击后有 `loading` |
| 后端未连接 | 顶部红点「未连接」；`开始识别` 禁用；主区显示 `Alert：无法连接到后端，请确认后端已启动` |
| 后端中途断开 | WebSocket 触发重连；顶部红点；重连成功恢复绿点并自动重新拉取配置 |
| 接口错误 | `message.error` 显示后端返回的 `detail` 或通用错误文案；按钮恢复可用 |
| 占位功能 | 见下节文案；一律不触发任何"假装成功"的流程 |

## 6. "占位功能"的展示文案（统一话术，避免误导）

| 占位功能 | 界面文案 |
|---|---|
| 加载 `.mat` 文件 | `真实 SEED 数据解析功能待接入` |
| 全部 62 通道（性能模式） | `性能模式未实现，第一版仅显示 8 个代表通道` |
| DE 微分熵 | `DE 微分熵为占位选项，尚未实现` |
| 特征说明 | `第一版特征选择主要用于演示与可视化；真实训练管线后续接入。` |
| SVM 模型 | `SVM 模型接口已预留，真实推理待接入 SEED 特征后实现` |
| CNN / CNN-LSTM | `占位选项，尚未实现` |
| 真实数据模式 | 顶部标签显示 `真实数据模式（占位）` |
| 选中未实现模型仍点开始 | 日志/提示：`所选模型尚未实现，当前仍使用模拟分类器` |

**统一原则：** 所有占位功能都以 `Alert`、`Tooltip`、`Tag（占位）` 或日志的形式给出上述文案；**永远不弹"成功"或输出伪造结果。**
