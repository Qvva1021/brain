## 1. 模拟 EEG 数据格式设计

### 1.1 单个数据块（一个 WebSocket 推送）

| 字段 | 值 | 说明 |
|---|---|---|
| 通道数 | 62（全量）；推送仅含 8 个代表通道 | 全量在内存计算，推送精简 |
| 每通道点数（块大小） | 25 个采样点 | 250 Hz ÷ 10 次/秒 = 25 点/块 |
| 推送间隔 | 100 ms | 每秒 10 块 |
| 采样率 | 250 Hz | 每秒 250 个采样点 |
| 时间轴 | 浮点 Unix 秒 | 前端用来定位最新数据 |

### 1.2 波形合成的数学模型

**第一版模拟波形 = 多个正弦波成分 + 小幅随机噪声，不是纯随机数。** 每个通道独立生成，公式示意：

```text
signal(t) = Σ_k  A_k * sin(2π * f_k * t + φ_k) + noise(t)
```

其中：

| 成分 | 频率 f_k | 用途 |
|---|---|---|
| 低频漂移 | 约 0.5–1 Hz | 让波形有缓慢起伏，更接近真实脑电外观 |
| α 节律 | 8–13 Hz | 放松/平静时增强（示例性设定，见下） |
| β 节律 | 13–30 Hz | 活跃/专注时增强（示例性设定，见下） |
| 噪声 | 全频段小幅随机 | 模拟采集噪声，让波形不显得"太假" |

振幅 `A_k` 由**当前模拟模式**决定（见下表），初相位 `φ_k` 每个通道随机，保证各通道波形不同。

### 1.3 三种模拟模式的频段强度差异

> ⚠️ **重要声明：以下"不同情绪对应不同频段强弱"的对应关系是课程教学用的简化设定，不代表真实临床/科研规律。** 真实脑电与情绪的关系仍在研究中，没有简单一一对应。

| 模式 | 内部标签 | 波形特征（教学设定） | 效果 |
|---|---|---|---|
| 高兴 | `positive` | α 强度中等、β 强度较高、振幅略大 | PSD 在 β 区相对突出 |
| 平静 | `neutral` | α 强度较高、β 强度较低 | PSD 在 α 区相对突出 |
| 悲伤 | `negative` | α、β 均较低、低频漂移略强 | PSD 整体偏低、低频占比略高 |

这样做能让切换模式时 PSD 图有**可观察的合理变化**，方便演示；但**绝不**对外声称"这就是真实情绪对应的脑电规律"。

### 1.4 62 通道与代表通道

- 全量 62 通道在内存中用一个 `(62, 25)` 的 NumPy 数组表示；
- 第一版只推送 **8 个代表通道**：`Fp1, Fp2, F3, F4, C3, C4, O1, O2`；
  - 通道名含义（人话）：F=额叶（Frontal）、C=中央（Central）、O=枕叶（Occipital）、P=顶叶（Parietal），字母后的数字与 `z`（中线）表示电极位置；`Fp1/Fp2` 为额极。
- 8 个代表通道恰好覆盖头部前、中、后、左、右不同区域，足够演示，又不会画 62 条线挤成一团；
- 「全部 62 通道（性能模式，占位）」选项第一版不实现渲染，仅提示。

## 2. 采样率、时间窗口、推送频率建议

| 参数 | 第一版值 | 理由 |
|---|---|---|
| 采样率 | 250 Hz | SEED 数据集原始采样率即是 250 Hz（未来可直接复用同一节奏） |
| 每块点数 | 25 点 | 250/10 = 25，配合 100 ms 推送 |
| 推送频率 | 10 块/秒 | 波形滚动流畅，又不至于占用太多带宽 |
| 前端保留窗口 | 约 5 秒（1250 点/通道） | 波形图横向 5 秒时间轴，看得到"滚动"效果 |
| PSD 计算窗口 | 最近 1 秒（250 点） | 与推送节奏匹配，频谱更新平滑 |

> 前端 `eegData` 状态用环形缓冲或"拼接 + 截断"保留最近 5 秒即可，不需要无限增长。

## 3. PSD 的概念、计算流程和输出格式

### 3.1 PSD 是什么（零基础版）

**PSD（功率谱密度，Power Spectral Density）**：把一段波形"拆解"成不同频率成分，横轴是频率（Hz）、纵轴是该频率上的能量（功率）。简单说：**波形里哪些频率的成分强，PSD 图上哪座山峰就高。**

### 3.2 为什么用它

- 情绪相关研究常看不同频段（δ/θ/α/β/γ）能量的强弱差异；
- PSD 是未来 SVM 的**候选特征输入**（把各频段能量打包成一个特征向量）；
- 对演示来说，PSD 图比原始波形更直观地反映"模式切换带来的差异"。

### 3.3 计算流程（第一版）

```text
取最近 1 秒的某代表通道（如 Fp1）的 250 个点
        ↓
scipy.signal.welch(x, fs=250, nperseg=128, noverlap=64)
        ↓
得到 (freqs, psd) 两个数组
        ↓
截取 1–50 Hz 范围
        ↓
psd 转成 dB（10 * log10(psd + 1e-12)，加极小值避免 log(0)）
        ↓
打包进 /ws/eeg-stream 的 eeg 消息：psd_freqs、psd_values
        ↓
前端 SpectrumChart 直接画图
```

### 3.4 输出格式（与文档 05 一致）

```json
{
  "psd_freqs": [1.0, 1.2, 1.4, "...", 50.0],
  "psd_values": [0.35, 0.33, "...", 0.01]
}
```

- `psd_freqs`：1–50 Hz 的频率点（步长取决于 welch 参数）；
- `psd_values`：对应频率的功率（dB）。

## 4. DE、ERP、原始波形的区别与使用边界

| 概念 | 中文 | 人话解释 | 本项目边界 |
|---|---|---|---|
| 原始波形 | Raw Waveform | 电极直接采到的、未加工的连续信号曲线 | 第一版主图（实时波形），用于演示与可视化 |
| PSD | 功率谱密度 | 波形的"频率成分谱"，看哪个频段能量强 | 第一版实现：PSD 频谱图 + 未来 SVM 特征 |
| DE | 微分熵 | 一种衡量信号"信息量/不确定性"的统计量，公式较复杂，常用于情绪研究 | **第一版只保留选项（占位）**；未来可基于 PSD 计算结果派生（对频段能量取对数后做香农熵类运算），不在第一版实现 |
| ERP | 事件相关电位 | 给刺激后固定时间窗内的特征波形，研究"反应"用 | 与"情绪识别"任务不匹配，**不实现**；仅在帮助文档中解释 |

**一句话边界：** 第一版只做"原始波形展示 + PSD 可视化"；DE 是占位选项；ERP 明确不做。

## 5. 模拟分类器逻辑（mock_predict）

### 5.1 输入
- 当前模拟模式（`positive / neutral / negative`）；
- （可选）最近窗口的简单统计量，如 PSD 各频段均值——第一版可只依赖模式即可，保持最简。

### 5.2 输出（与文档 05 `EmotionResult` 一致）
| 字段 | 规则 |
|---|---|
| `emotion` | 与当前模拟模式一致的类别，**不随机跳变** |
| `emotion_zh` | 对应中文 |
| `confidence` | 0.60–0.95 之间，基于模式 + 小幅随机扰动（如 `0.78 + random(-0.05, 0.05)` 再裁剪到范围） |
| `model_name` | `模拟分类器` |
| `data_source` | `模拟数据` |
| `timestamp` | 推理时刻 |

### 5.3 时序控制
- 识别开启后，**每 2–5 秒**随机取一个间隔执行一次推理并推送；
- 结果与上一次差别很小（同一模式下只在置信度上有 ±5% 扰动），避免看起来"乱跳"；
- 切换模拟模式后，下一次推理自然切换到新类别。

### 5.4 为什么这样设计
- 让结果稳定、可解释、便于演示（"平静"不会一下变"悲伤"）；
- 保留一点随机性，看起来更像真实模型的输出；
- 明确标注来源为"模拟分类器"，不冒充真实模型。

## 6. 未来 SEED 数据接入步骤

> 以下为**设计草案**，供第二阶段实现。SEED 数据集以 `.mat` 文件保存（**MATLAB 数据文件**，不是普通 CSV），内部结构因版本而异，**第一版不做任何字段名硬编码**，以实际文件说明为准。

```text
1. 用户选择 .mat 文件（前端 Upload）
2. 后端 POST /api/data/load 接收路径（真实实现时接收文件）
3. 用 scipy.io.loadmat(file_path) 读取
4. 按该版本 SEED 的官方说明，找到：
   - 脑电数据数组（通常为 通道数 × 采样点数 × 试次数）
   - 标签数组（每段对应的情绪标签）
   - 采样率（SEED 为 250 Hz）
5. 检查数据结构 → 转成统一的 "EEGWindow" 内存结构（复用第一版的管道）
6. data_source 切换为 "已加载文件（SEED）"
7. 可选：按试次回放窗口，模拟"实时流"
```

**必须注意：**
- 不同 SEED 版本的文件变量名、维度顺序可能不同，**必须先做结构探测与校验**；
- 不要假设 `data`、`label` 之类的变量名一定存在；
- 读取后先打印/校验形状与范围，避免静默错误。

## 7. 未来 SVM 训练与模型加载步骤

### 7.1 离线训练（不在运行演示的电脑上实时进行）

```text
1. 读取若干 SEED 受试者数据（训练集）
2. 对每个窗口提取特征向量（第一版优先 PSD：各频段能量拼接）
3. 准备标签 y（positive/neutral/negative）
4. 划分训练/验证集（交叉验证用于评估，见术语表）
5. scikit-learn: SVC(probability=True) 或线性 SVM
6. 保存模型: joblib.dump(model, "models/svm_psd.joblib")
```

### 7.2 运行时加载与推理

```text
1. 后端启动时（或首次使用真实模式时）
   joblib.load("models/svm_psd.joblib")
2. 收到窗口 → 提取相同格式的 PSD 特征向量
3. model.predict_proba(features) → 得到三类概率
4. 取最大概率类别 → 作为置信度
5. 输出与 EmotionResult 同结构，但 model_name="SVM 模型"
```

### 7.3 特征一致性铁律

> **训练时的特征和运行时的特征必须完全一致**（同样的频段、同样的窗口长度、同样的采样率、同样的预处理）。这是机器学习最常踩的坑。文档 06 会在未来版本维护一份"特征规范"。

### 7.4 训练脚本放哪里

建议未来放到 `scripts/train_svm.py`（见文档 07），与运行时的后端分离；第一版不创建。

## 8. 为什么不能把"高兴/平静/悲伤"直接写死为真实识别结论

| 理由 | 说明 |
|---|---|
| 标签来源不同 | 第一版标签来自"模拟模式设定"，不是任何模型或真实数据判定 |
| 情绪与脑电无简单映射 | 情绪受情境、个体差异、电极位置、噪声等多种因素影响，同一个 PSD 图可能对应不同情绪 |
| 数据非真实 | 模拟波形的人为合成，不携带任何真实生理信息 |
| 防止误导 | 若界面直接写"识别到您处于高兴状态"，老师或用户会误以为系统具备真实情绪读取能力，这是危险的误导 |
| 教学诚实 | 课程 Demo 的价值在于展示"工程链路 + 算法流程"，而不是伪造临床结论 |

因此所有结果必须：带 `model_name`、带 `data_source`、带免责声明；模拟模式下文案一律说"模拟分类器输出"，而非"系统准确识别了您的情绪"。
