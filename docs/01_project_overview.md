# 文档 01：项目总览（Project Overview）

> 适用读者：完全零基础的初学者。本文件先讲"这个项目是什么、要做什么、不做什么"，再给出全文通用的术语速查表。后续所有文档默认读者已读过本文件。

---

## 1. 项目名称

| 项目 | 名称 |
|---|---|
| 英文名 | **EEG Emotion Recognition System**（脑电情绪识别系统） |
| 中文名 | **脑电情绪识别演示系统** |
| 中文副标题 | 脑电情绪识别演示系统 |
| 版本 | v0.1（第一版：全模拟演示版） |
| 文档日期 | 2026-08-28 |

第一版的产品定位是：**一个在浏览器里运行、能"看起来像真的"完成从生成脑电波形 → 实时滚动显示 → 输出情绪识别结果的课程演示系统。**

> **脑电（EEG）**：Electroencephalogram 的缩写，中文叫"脑电图"。它描述的是用贴在头皮上的电极记录到的大脑皮层神经活动的电信号波形，是本项目唯一的数据输入来源。第一版里这些波形由后端模拟生成，未来替换成 SEED 数据集里的真实脑电记录。

---

## 2. 项目目标（Goals）

第一版（v0.1）的目标如下，全部要求**在没有真实数据、没有真实模型、没有 EEG 硬件的情况下**也能完整运行和演示：

1. **跑通一条完整演示链路**：启动 Python 后端 → 启动 React 前端 → 前端连接后端 → 后端自动生成模拟的 62 通道 EEG 波形 → 前端以"实时滚动波形"显示 → 点击"开始识别" → 后端返回情绪类别与置信度 → 前端显示结果。
2. **做出一套界面完整、逻辑清楚、可演示的前端**：包含顶部导航栏、左侧控制面板、主显示区（实时波形 + 频谱图 + 情绪结果 + 历史记录）、底部状态栏。
3. **后端提供真实可运行的接口**：REST API（健康检查、配置、开始/停止识别等）和 WebSocket（实时推送波形与情绪结果），并做到"模拟数据由后端生成，前端不自己造假数据"。
4. **用模拟分类器产生稳定、合理的演示结果**：结果不会每 50 毫秒乱跳，而是每隔 2–5 秒更新一次，输出情绪类别 + 置信度 + 时间戳。
5. **为后续版本预留清晰的接口边界**：文件上传、SEED `.mat` 解析、特征提取（优先 PSD）、SVM 模型推理等，第一版只留接口和说明，不做真实现。
6. **文档与代码保持一致**：凡是文档里写"已实现"的，代码必须能真正运行；凡是"占位"的，界面上必须明确标注，不能假装已实现。

## 3. 非目标（Non-Goals）——本期明确不做什么

以下是第一版**明确不做**的事，避免把课程 Demo 做成商业系统：

| 序号 | 不做什么 | 原因 |
|---|---|---|
| 1 | 不做医疗诊断、不输出任何疾病/健康结论 | 课程 Demo 不是医疗产品；免责声明见第 8 节 |
| 2 | 不读取真实 SEED `.mat` 文件 | 第一版不依赖任何真实数据文件，只留接口 |
| 3 | 不训练真实机器学习模型 | 第一版用"模拟分类器"代替，不做 SVM/CNN 训练 |
| 4 | 不接入真实 EEG 硬件 | 不连接任何脑电采集设备 |
| 5 | 不使用数据库、账号、认证 | 历史记录只保存在后端内存里，刷新重启即丢失 |
| 6 | 不使用 Docker、云部署、消息队列、Redis、Celery | 超出本地 Demo 必要范围 |
| 7 | 不使用 Redux 等重型状态管理、不引入多余图表库 | 保持前端简单可学习 |
| 8 | 不在后端提前引入 TensorFlow/PyTorch/MNE/pandas | 第一版没有真实模型和数据，装了也只是占位 |
| 9 | 不渲染全部 62 通道（性能模式仅作占位选项） | 62 条线叠在一起无法阅读，第一版只画代表通道 |
| 10 | 不声称"系统准确识别了用户的真实情绪" | 所有结果来源都标注为"模拟分类器" |

一句话总结非目标：**第一版是一个"能跑、能看、能讲、诚实标注占位"的教学演示，不是产品。**

## 5. Demo 使用流程（第一版）

```text
① 启动 Python 后端（FastAPI + Uvicorn）
        ↓
② 启动 React 前端（Vite 开发服务器）
        ↓
③ 浏览器打开 http://localhost:5173
        ↓
④ 顶部导航栏显示"后端已连接"（绿色）
        ↓
⑤ 后端开始自动推送模拟的 62 通道 EEG 波形数据
        ↓
⑥ 主显示区出现实时滚动的代表通道波形（如 Fp1/Fp2/F3/F4/C3/C4/O1/O2）
        ↓
⑦ 用户在左侧选择：模拟情绪模式、特征类型、模型
        ↓
⑧ 用户点击「开始识别」
        ↓
⑨ 每隔 2–5 秒，后端返回一次情绪识别结果（高兴/平静/悲伤 + 置信度）
        ↓
⑩ 前端更新：情绪结果卡片、情绪历史记录、运行日志
        ↓
⑪ 用户可随时「暂停波形」「继续波形」「停止识别」「重置演示」
        ↓
⑫ 关闭页面：前端退出；Ctrl+C 关闭后端
```

> 说明：第一版不需要任何真实 EEG 设备或 SEED 数据文件，**装好 Python 3.10 和 Node.js 就能完整演示**。

## 6. 课程展示价值（为什么这是一个好 Demo）

- **覆盖主流技术栈**：React + TypeScript + Vite 前端、FastAPI + Python 后端、WebSocket 实时通信、ECharts 数据可视化——每一项都是简历和课程报告中的常见关键词。
- **有一条完整的端到端链路**：从"数据生成"到"算法处理"再到"界面展示"，跨前端与后端，逻辑闭环。
- **算法概念真实可讲**：EEG、通道、PSD 频谱、特征、SVM、置信度等概念都有真实落点，不是空谈。
- **诚实且有扩展空间**：把"模拟"与"真实（占位）"分得清清楚楚，答辩时可以说"下一步如何接入 SEED 与 SVM"，展示工程思维。
- **界面专业**：科研仪表盘风格（波形 + 频谱 + 结果卡片 + 历史记录），截图放进课程报告很合适。
- **体量可控**：MVP 最小可行实现，代码量小、依赖少，初学者看得懂。

## 7. 术语速查表（面向零基础）

> 使用约定：本文档及后续所有文档中，**每个术语第一次出现时**，都会给出：中文名称 / 英文名称 / 一句人话解释 / 在本项目中的职责。下表是汇总版，方便随时查。

### 7.1 领域术语（EEG / 算法）

| 术语 | 中文名称 | 英文名称 | 人话解释 | 在本项目中的职责 |
|---|---|---|---|---|
| EEG | 脑电信号 / 脑电图 | Electroencephalogram | 贴在头皮上的电极记录到的大脑神经活动的微弱电信号，画出来是一堆起伏的波形 | 本系统的输入数据；第一版由后端模拟生成，未来换成 SEED 真实数据 |
| Channel | 脑电通道 / 电极 | Channel / Electrode | 脑电帽上的一个金属接触点，负责采某一个位置的头皮电位，每个通道画出一条波形 | 第一版模拟 62 个通道，界面默认只展示 8 个代表通道（Fp1、Fp2、F3、F4、C3、C4、O1、O2） |
| 采样率 | 采样率 | Sample Rate | 每秒钟对连续信号取多少个样点数，单位 Hz；采样率越高，波形越精细 | 本项目模拟模式固定为 250 Hz，即每秒采集 250 个点 |
| Feature | 特征 | Feature | 从原始波形里提炼出来的、更能代表"这段脑电是什么状态"的数字信息 | 未来喂给 SVM 模型做分类；第一版主要做可视化演示 |
| PSD | 功率谱密度 | Power Spectral Density | 把一段波形按"频率"拆开，看看哪个频率上的能量强；可以理解为"波形的频率成分谱" | 第一版由模拟波形用 Welch 方法计算，绘制 1–50 Hz 频谱图；未来作为 SVM 的特征输入 |
| DE | 微分熵 | Differential Entropy | 一种描述信号"不确定度/信息量"的统计量，常用于脑电情绪识别研究 | 第一版**只保留选项，不实现**；未来可作为特征，见文档 06 |
| ERP | 事件相关电位 | Event-Related Potential | 给受试者一个刺激（如声音/图片）后，脑电在固定时间窗内出现的特征性波形 | 与"情绪识别"任务不直接相关，**仅用于说明文档**，本项目不实现 |
| 频段 | 脑电频段 | Frequency Band | 按频率把脑电分成几段，各段与不同的心理/生理状态有关（δ/θ/α/β/γ） | 界面用于给频谱图着色分区，并作为模拟波形合成的依据 |
| α 节律 / β 节律 | 阿尔法/贝塔节律 | Alpha / Beta Rhythm | α（8–13 Hz）多在放松闭眼时增强，β（13–30 Hz）多在清醒、专注时增强 | 模拟波形用这些频率成分合成，让波形"看起来像脑电" |
| Confidence | 置信度 | Confidence | 模型对自己判断"多确定"的度量，用百分比表示，如 82% | 前端在结果卡片里用大字显示，并配进度条 |
| Cross-validation | 交叉验证 | Cross-Validation | 把训练数据分成几份，轮流用其中一部分测试、其余训练，用来评估模型泛化能力 | 属于"未来训练真实模型"时的评估手段，不属于第一版实时界面功能 |

### 7.2 机器学习模型术语

| 术语 | 中文名称 | 英文名称 | 人话解释 | 在本项目中的职责 |
|---|---|---|---|---|
| SVM | 支持向量机 | Support Vector Machine | 一种经典监督学习模型，在特征空间里找一个"分界线"把不同类别分开 | 第一版真实模型的优先选择；**第一版由模拟分类器替代，仅预留接口** |
| CNN | 卷积神经网络 | Convolutional Neural Network | 擅长处理图像/网格结构数据的深度神经网络 | 后续扩展模型；第一版界面中显示为"未实现/占位" |
| LSTM / GRU | 长短期记忆 / 门控循环单元 | Long Short-Term Memory / Gated Recurrent Unit | 擅长处理时间序列、能"记住"前后文关系的循环神经网络 | 后续扩展模型；第一版不训练 |
| Transformer | Transformer 模型 | Transformer | 基于注意力机制（attention）的深度学习模型，如今大模型的主流底座 | 后续扩展模型；第一版不训练 |
| 训练 | 训练 | Training | 用大量"数据 + 标签"让模型学会规律的过程 | 第一版不进行；未来用 SEED 数据训练 SVM |
| 推理 | 推理 / 预测 | Inference / Prediction | 把训练好的模型拿给新的数据用，让它输出一个结果 | 第一版用"模拟分类器"模拟这个过程 |

## 8. 医疗免责声明（Medical Disclaimer）

> ⚠️ **请将以下声明原样展示在界面底部，并保留在 README 中。**

**本系统仅用于教学与算法演示，不用于医疗诊断。**

- 系统输出的"高兴 / 平静 / 悲伤"结果是**模拟分类器生成的演示数据**，不代表对任何人的真实情绪或健康状况的判定。
- 系统不含、也不声称具备医疗诊断、疾病筛查、疗效评估等任何医疗功能。
- 真实脑电情绪识别本身仍处于研究阶段，情绪与脑电之间不存在"一一对应"的确定性关系；任何临床判断都必须由专业医疗机构完成。
- 若未来接入真实数据与训练模型，输出结果仍仅代表"模型的预测"，仍需以上述方式显著标注。
